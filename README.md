This container have reports used as demo for show a general knowledge of visuals and functionality that I can add to Power BI report.

'/data': Data files as sources for reports
'/documentation': Technicals notes, business assumptions, KPIs definitions, etc.
'/images': Screen shots of reports open in Power BI Services.
'/model': Documentation of data model, DAX functions or other technical items.
